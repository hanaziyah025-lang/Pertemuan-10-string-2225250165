## Algoritma
1. Menerima input nama mahasiswa dan kode kelas.
2. Membersihkan spasi berlebih pada nama.
3. Mengubah nama menjadi title case.
4. Mengubah kode kelas menjadi huruf kapital dan mengganti spasi dengan tanda hubung.
5. Menghitung jumlah kata dan membentuk inisial nama.
6. Menampilkan hasil normalisasi.
